VEX Event Display Setup

Enter the event details, then open or share the display link. Every setting is stored in the link, so any device that opens it shows the same display. Nothing is saved on a server.

Display link

Scan this with a phone or tablet to open the same display. To change settings later, tap the gear in the top-right corner of a display; it opens this page with that display's settings filled in.

Tournaments shown on the display

Single uses the High School settings below. Demo mode plays a whole event (one qualification match every 3 seconds, a lunch break, rankings, then the bracket) and starts over; it needs no SKU or token.

Every device that opens the link asks events.vex.com for data itself (2 requests per tournament per refresh). If many phones use the same token, use a longer refresh (30–60 s) for public links so events.vex.com doesn't rate-limit it.
